# Matabaat — Android MVP

Kotlin Android starter for floating road-hazard alerts while using navigation apps such as Google Maps.

## MVP features
- Floating overlay bubble.
- GPS location tracking through a foreground service.
- Local reports for speed cameras, speed bumps, and potholes.
- Nearest saved hazard display and proximity alert.

## Limitations
- Reports are stored locally on this device and are not shared.
- No verified Egypt radar/bump dataset is included.
- Road direction is not filtered; parallel or opposite-road reports may appear.
- Location/report accuracy depends on GPS availability and Android background restrictions.
- Do not interact with the phone while driving; obey posted speed limits.

This is an experimental starter project, not a production navigation or safety system.
